# Novid Studio 设计规范

使用 ui-ux-pro-max 的 `knowledge productivity workspace minimal` 与 `SaaS dashboard workspace` 检索，并结合已有 Vue 3 / Element Plus 实现。查询返回的营销页结构不适合私人工作台，因此采用通用平面设计、内容优先的应用布局；配色针对 Novid 调整，不保存未核验的营销页建议。

- 桌面：固定深靛导航、白色位置栏、浅灰内容区；内容最大宽度 1440px。800px 以下使用支持焦点管理与 Escape 的导航抽屉。
- 主色 #5145CD；背景 #F5F6FA；正文 #202639；次要正文 #5F697D；导航 #171C30。所有新增组件使用 studio.css 的语义变量。
- 使用本地系统字体和中文回退，避免外部字体请求。正文 15px，移动端 16px；辅助说明至少 12px；标题 26–36px。
- 4/8px 间距体系；卡片 16px 圆角；信息分组使用留白、边框和弱底色。禁止用动画、计时或虚构数据推算进度。
- 延续 Element Plus 的统一 SVG 图标。装饰图标 aria-hidden，按钮必须有可读名称。键盘焦点可见；路由变化聚焦主要内容；导航有跳过链接。
- 常规反馈 160ms；尊重 prefers-reduced-motion。页面和表单保持可缩放；输入、选择与按钮支持窄屏重排。
- 问答采用会话工作区：左侧 252px 会话列表，右侧当前聊天与固定底部输入；聊天页去除额外大标题和页脚，充分利用视口。1100px 以下会话列表改为抽屉。模型、输出、工具、流式和范围参数集中在右上角设置面板，抽屉支持焦点管理和 Escape。资料页区分文档、处理中和就绪事实。任务创建按报告/PPT/视频渐进展示选项。
- 费用独立查询，估算、预留、未知分开，不浮点累加金额。媒体预览批准与最终本人验收分开；未知结果不提供重购按钮。
- PPT 页数包含来源页。PNG/PPTX/MP4 使用认证 Blob 读取；不将令牌或内部 storageKey 写入 URL。修改版本、拒绝或撤权后清理已展示的私人附件。

验证视口：375×812、812×375、768×1024、1440×1000；同时检查减少动效与键盘操作。
