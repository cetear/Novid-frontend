# 测试与验收指南

更新日期：2026-10-13。依据 [测试脚本](../../package.json)、[Playwright 配置](../../playwright.config.ts)、[后端预检](../../scripts/check-backend.mjs) 和现有报告。

模型调用归档可先执行只读 `node scripts/check-model-calls.mjs`。创建新真实批次需要明确执行 `node scripts/create-model-call-fixture.mjs`，会产生真实模型费用；再运行 `live-model-calls.spec.ts --project=live`，最后用 `live-model-calls-cleanup.spec.ts --project=live` 清理本批合成资料并验证撤销。正式调用前加 `pnpm exec playwright test tests/e2e/`。详见 [10-13 归档报告](live-integration-2026-10-13-model-calls.md)，默认测试不会创建该模型任务。

最新续跑验证可执行 `node scripts/check-task-retry.mjs` 和 `pnpm exec playwright test tests/e2e/live-retry.spec.ts --project=live`，使用 `.env.live.local` 受控账号。脚本只对历史测试任务发送确定无资格或版本过期的请求；浏览器只展示资格，不触发成功续跑。`NOVID_RETRY_TASK_ID` 可指定真实页面验证的本人失败整编任务。结果见 [10-12 续跑报告](live-integration-2026-10-12-retry.md)。

## 测试层次与执行

在项目根目录使用 Node 24 和 pnpm 11.19.0：

| 命令 | 验证范围 | 是否使用真实模型 |
| --- | --- | --- |
| `pnpm type-check` | TypeScript 与 Vue 类型 | 否 |
| `pnpm lint`、`pnpm format:check` | 源码、测试和工程配置规范 | 否 |
| `pnpm test` | Vitest 通信、字段、SSE、版本和安全显示 | 否 |
| `pnpm build` | 类型检查与生产构建 | 否 |
| `pnpm test:e2e` | 构建后在 4173 使用 Chrome 和显式 Mock 接口验证浏览器流程 | 否 |
| `pnpm test:backend` | 后端与 5173 代理健康、匿名访问和无效登录，6 项预检 | 否 |
| `pnpm test:e2e:live` | 当前 V3 单文档自测、整编保存、生成资料自测和 PPT V2 | 是，依次运行合成资料任务 |
| `pnpm docs:check` | 根 README 与 docs 下 Markdown 本地链接目标存在性 | 否 |

预检要求后端和开发服务器已启动，健康检查不满足预期时返回非零。预检默认后端 `http://localhost:8080`、前端 `http://127.0.0.1:5173`；可通过终端 `API_PROXY_TARGET`、`NOVID_TEST_ORIGIN` 调整。Playwright 目前显式固定两个项目的地址，不能只改预检变量就认为浏览器地址也变了。

## 真实后端联调

真实账号通过当前终端环境变量或 Git 忽略的 `.env.live.local` 提供：

```powershell
$env:NOVID_TEST_USERNAME = '后端提供的受控用户名'
$env:NOVID_TEST_PASSWORD = '后端提供的测试密码'
pnpm test:backend
pnpm test:e2e:live
```

Playwright 默认使用本机 Google Chrome，真实项目关闭截图和 trace，retries=0。默认只执行当前 `live-v3.spec.ts`；历史主协议、SSE 和 V2 用例保留，可按文件显式运行。历史只读观测依赖主协议生成的 `protocol-v2-2026-10-09.json` 脱敏证据，单独运行前须先运行主协议。缺少凭证会跳过需要登录的用例，跳过不能计为通过。

V3 每个任务最多观察 45 分钟，顺序创建。PPT 验证停在审批前，不批准媒体购买；成功产物在来源清理前保存。同批 `live-v3-readback.spec.ts` 只复用已有任务和确认记录，验证深链接重新登录、保存、入库和来源绑定，不重新创建模型任务。

真实测试会创建独立合成资料、会话和学习任务，触发实际 embedding 和模型调用。结束时逻辑删除本次资料、版本删除会话、拒绝未决定的笔记确认、取消未结束任务、撤销登录；新建测试用户禁用。已完成任务和已决定确认没有删除接口，保留记录。只清理本次创建的资源，不修改提供账号的密码、角色或后端配置。

需要单独定位已失败场景时，可按文件显式执行：

```powershell
pnpm exec playwright test tests/e2e/live-protocol.spec.ts --project=live --reporter=line
pnpm exec playwright test tests/e2e/live-readback.spec.ts --project=live --reporter=line
pnpm exec playwright test tests/e2e/live-sse.spec.ts --project=live --reporter=line
pnpm exec playwright test tests/e2e/live-v2.spec.ts --project=live --reporter=line
```

V2 三类任务测试默认观察最多 30 分钟。仅补测整编可设置 `$env:NOVID_V2_COMPILATION_ONLY='1'`，结束后删除该环境变量，证据保存为 `v2-compilation-2026-10-09.json`，不会覆盖首批。`scripts/observe-v2.mjs` 仅复核已有 PPT 原任务，须明确提供 `NOVID_V2_OBSERVE_TASK_ID` 与 `NOVID_V2_OBSERVE_DOCUMENT_ID`；它不会创建新任务或批准费用。

登录存在按账号的时间窗口限流，429 后等待窗口恢复；不要自动循环登录或重发模型请求。已成功的付费模型场景不因无关测试断言修复而机械重复。

## 证据与记录规则

浏览器 HTML 报告按项目隔离在 `playwright-report/contract/`、`playwright-report/live/`；同批 V3 复核使用 `playwright-report/live-v3-readback/`。受控接口截图在 `var/screenshots/`，真实脱敏证据在 `var/live/`，均被 Git 忽略。预检和部分证据文件会被下一次运行覆盖，保留批次时先按日期另存脱敏副本。不要将令牌、密码、模型密钥、模型地址或原始私密提示词写入报告。

新增验收使用 `live-integration-YYYY-MM-DD.md`；同日多轮分别标明批次和命令。记录日期 / 时区、前后端环境、协议范围、真实或 Mock、通过 / 失败 / 跳过、资源清理、证据路径和未覆盖边界。保留初次失败及修复后复测，不把分批成功合并称为同一批全通过。

READY 要有实际索引激活事实；SSE 要由应用消费并完整结束；报告要有真实终态、产物 ID、预览和下载；来源撤销要验证实际访问限制。覆盖完成、提供方用量或 `mock=false` 分别说明对应事实，不自动证明质量、价格或故障切换已经验收。
