### 浏览器场景

1. 错误凭证、登录、刷新清除内存身份；没有浏览器运行异常。
2. 首次改密，原密码 401 后 me 复核保持身份；修改成功重新登录。
3. SSE 最终覆盖、旧版本证据复核、准备笔记→全部来源预览→批准→文档入口。
4. 文档空中间页继续翻页，库禁用后通过已知 ID 恢复。
5. 报告暂停 / 恢复、PARTIAL、按 artifactId 预览与下载、来源拒绝后清理报告。
6. 记忆版本 403 后读取本人列表，保留草稿且不登出、不自动覆盖。
7. ADMIN 对他人知识库只读、临时密码一次性展示。
8. 390px 窄屏导航与问答、无横向溢出，USER 无管理员入口。
9. 浏览器 UTF-8 Markdown 文件上传，校验 multipart / Bearer / 幂等头；202 后仍为待处理，显示后台等待提示。

手工查看过登录、桌面问答与窄屏截图，修正了空状态下输入框遮挡建议卡片的问题。截图位于忽略目录 var/screenshots/，其中登录身份与消息来自测试夹具，没有真实账号密码。

### 已处理的验收问题

- 空正文不进行 JSON 解析；普通 401 与改密 401 策略分离。
- done 替换累积文本并继续读取到正常 EOF，断流 / 未终止事件 / 第二终态失败，不自动重发。
- 旧 READY 不确认重处理完成；正文版本变化也不误报索引激活。
- 观察页面销毁后，晚到的动作响应不能重新启动后台轮询。
- 开发服务器预构建完整组件依赖并忽略测试报告文件，避免新依赖 / 报告刷新清除内存身份；正式浏览器验收使用构建产物。
