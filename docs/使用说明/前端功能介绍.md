# 前端功能介绍

更新日期：2026-10-09。依据当前页面与路由实现；当前真实验收范围见 [V2 联调报告](../测试验收/live-integration-2026-10-09-v2.md)，本次更新见 [V2 开发记录](../开发维护/development-2026-10-09-v2.md)，操作步骤见 [前端使用说明](前端使用说明.md)。

Novid 前端是知识工作台：上传资料到知识库，基于资料提问并查看引用，经确认将回答保存为笔记，或生成学习自测、整编文档、PPT 和视频。后台负责权限校验、资料入库、检索、模型执行和结果生成；页面显示实际返回状态。

## 功能与入口

| 功能 | 页面入口 | 当前能力 |
| --- | --- | --- |
| 登录与账户 | `/login`、`/settings`、`/change-password` | 登录、身份核验、首次改密、主动改密、退出、显示间距偏好 |
| 知识库 | `/knowledge-bases` | 范围切换、统计、本人知识库创建和编辑、禁用、按已知 ID 恢复、删除 |
| 文档与入库 | `/documents/:id`，由知识库详情进入 | UTF-8 TXT / Markdown 上传、原文展示与下载、版本修订、删除、目录与小片分页、章节续读、本人入库进度与原代次恢复 |
| 知识问答 | `/chat` | 单轮或本人会话、JSON / 流式回答、模型逻辑配置、结构化校验、只读工具续轮、引用查看 |
| 会话历史 | 知识问答页中的本人会话区 | 新建、分页列表、服务端历史、后续历史读取、版本核对和删除；受限历史显示占位 |
| 回答笔记 | 问答页准备，`/approvals/:approvalId` 确认 | 选择本人目标库、预览完整笔记及全部来源、批准或拒绝，批准后进入保存文档 |
| 学习与制作 | `/tasks`、`/tasks/:id` | 学习自测、资料整编；六阶段进度、私人 JSON、答案折叠、目录正文、引用定位、暂停 / 恢复 / 取消、Markdown 下载；PPT / 视频审批与验收；历史 FAQ / 报告只读查询 |
| 个人偏好 | `/memories` | 明确新增、查询、更正和删除本人偏好，版本冲突后核对 |
| 运行检查 | `/runs`、`/runs/:traceId` | 本人运行列表、持久节点、依赖、时间线、上一执行、提供方已知用量与未知费用状态 |
| 用户管理 | `/admin/users`，仅管理员 | 创建普通用户、一次性临时密码展示、启用状态与角色调整 |

表中的 `:id`、`:approvalId`、`:traceId` 是对应资源的实际标识。页面是否允许操作仍由服务端权限和当前状态决定。

## 角色与资料范围

| 场景 | 普通用户 USER | 管理员 ADMIN |
| --- | --- | --- |
| 本人知识资料 | 读取和管理本人资料 | 读取和管理本人资料 |
| 他人有效知识资料 | 不允许 | 可按授权范围读取，不能修改或删除他人资料 |
| 全部授权资料范围、按资料所有者筛选 | 不提供管理员范围 | 提供相应读取选项 |
| 会话、任务、计划、笔记确认、偏好、运行 | 仅本人 | 仍仅本人 |
| 入库管理操作 | 仅本人文档 | 仍仅本人文档 |
| 用户管理 | 无入口 | 可管理用户 |

当前没有公开注册和默认账号，账号由后端管理员提供。

## 数据与完成状态

上传接收成功不等于资料可检索，文档最终核验并激活为 READY 后才算就绪。流式回答在正常结束后显示“完整交付”；停止阅读或网络中断不能据此确认后台未保存回答，应核对服务端历史。

自测、整编和 PPT 采用资料与可选备注，数量默认自动规划；题数、章节上限可指定至 512，PPT 指定总页数为 2～512，含动态来源页。任务详情展示资料内容计划、数量理由与完成单元；旧计划入口已删除。原文容量默认合计 1,000,000 UTF-8 字节，由服务端创建时的策略决定。

学习任务 SUCCEEDED 后可读取私人结果；模型质检通过仍待人工判断内容质量，完整读取选中文档不代表穷尽全部知识点。历史报告 PARTIAL 表示存在限制，应结合阅读覆盖查看；旧 FAQ／研究报告不再创建或恢复。运行图缺失或未写完时明确标记不完整；已知用量不等于完整费用。

登录令牌、当前页面正文和本次登录的已知资源索引只在内存保存，刷新后需要重新登录。本人会话有服务端列表和历史；任务、确认和产物没有完整列表恢复接口，应保存页面地址或资源 ID。

2026-10-05 新增：报告任务页可创建 PPT／视频规划任务；详情页提供预览编辑、费用批准、真实操作查询、实测时间轴、PPT 页面检查和本人验收。费用入口 `/fees` 查询本人已知记录，管理员 `/admin/operations` 查看指标、币种费用聚合与访问审计。真实媒体效果不由前端契约测试代替。

当前仍无完整任务中心、全文搜索结果列表、模型配置管理、供应商实付账单或退款写接口。能力与联调限制集中维护于 [integration-gaps](../接口联调/integration-gaps.md)。
