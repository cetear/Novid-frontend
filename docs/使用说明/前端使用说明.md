# 前端使用说明

更新日期：2026-10-04。依据当前页面操作。首次启动项目见 [开发与部署](../开发维护/开发与部署.md)，功能与权限概览见 [前端功能介绍](前端功能介绍.md)。

## 登录和账户

打开已部署的前端地址，本机开发默认是 `http://127.0.0.1:5173`。输入管理员提供的账号和密码。首次登录要求改密时，先完成改密，再重新登录。正常使用期间可在设置页修改密码、调整显示间距或退出登录。

页面刷新会清除内存登录状态；重新登录后可通过原页面地址重新读取有权限的资源。密码修改成功后需要重新登录。修改密码时若原密码错误，按页面提示重新填写，不必据此认定登录已失效。

## 上传资料并确认可用

1. 打开“知识库”，选择“我的资料”，创建本人知识库或进入已有库。
2. 在库详情选择 UTF-8 编码的 `.txt` 或 `.md` 文件，点击上传。接收后进入文档详情查看处理状态。
3. 等待文档成为 READY。处理中查看“本人入库管理”的阶段、批次、已核验索引和错误提示；页面关闭不会取消后台入库。
4. 在“当前原文”查看正文；在“目录与小片”点击“加载当前结构”，按页查看目录或小片，用“定位原文”定位当前正文。
5. 点击“按章节续读”打开章节原文，存在未读内容时继续下一页。可使用“下载原文”保存当前可读版本。

修订资料时使用“保存新版本”，发生版本冲突先刷新核对。“提前恢复原代次”仅在页面允许时调度原失败代次；“重处理”会申请新代次，按提示明确决定。READY 的旧代次不代表新代次已经完成。

禁用知识库前保存库 ID 或详情页地址。禁用后普通列表会隐藏它，可在知识库页通过已知 ID 打开并重新启用。删除前核对目标；来源删除或失去访问权限可能使引用、笔记和报告受限。

## 单轮提问与本人会话

1. 打开“知识问答”，选择“我的资料”或指定知识库；管理员可选择界面提供的授权范围。
2. 临时提问使用“单轮问答”。需要连续交流时填写“新会话标题”并点击“新建会话”，或选择已有本人会话。
3. 选择模型配置、回答格式、工具续轮选项，输入问题，点击“发送问题”。默认勾选“流式展示”；取消勾选后使用 JSON 模式。
4. 等待“完整交付”，点击引用查看来源文档、版本及证据。当前版本证据可定位原文，旧版本证据按页面提示独立查看。
5. 后续问题在当前会话继续发送；“核对服务端历史”重新读取已保存版本和事件，“读取后续历史”继续加载历史。

“模型配置”是后端逻辑选项，包括自动选择、知识问答、经济、分析、报告，不代表已认证所有配置的质量。“只读工具”允许服务端执行可用的只读工具；当前界面会将回答格式固定为文本，可点击“查看可用工具”核对定义。

点击“停止阅读”、连接中断或出现会话版本冲突时，先核对服务端历史，再决定下一次提问。页面不会自动重复模型请求。“清空本页问答”只清除本页显示，删除服务端会话须使用“删除会话”。会话保存历史，但模型上下文有限；长期偏好请在个人偏好页明确保存。

## 将回答保存为笔记

1. 在有可用来源的回答上点击“准备保存笔记”。无来源统计回答不提供该入口。
2. 选择本人目标知识库，核对标题和内容，点击“准备并预览确认”。
3. 在确认页查看完整内容、目标库、全部来源依赖及期限。需要放弃时点击“拒绝保存”。
4. 内容与来源确认后点击“已核对，批准保存”。服务端返回 APPROVED 及保存文档入口后，才算保存成功。

决定前页面会重新核验确认记录。来源失效、超期或权限变化时按最新提示处理，不把准备成功当作笔记已入库。

## 生成 FAQ 或研究报告

1. 打开“报告任务”，选择 FAQ 或研究报告，填写主题和资料范围，按页面选项选择文档，最多 6 份。使用已 READY 且激活的文档；未就绪资料可以登记任务，但执行会失败。
2. 研究报告可选“固定流程”或“受限研究计划”；FAQ 使用固定流程。
3. 点击“创建报告任务”，保存任务详情页地址或任务 ID。创建成功表示任务被接收，仍需等待后台执行。
4. 查看五步进度、当前并行步骤、Worker 状态、心跳和“阅读覆盖”。受限研究报告可点击“查询计划”；固定流程或计划尚未生成时可能暂无计划。
5. 按当前状态使用暂停、恢复或取消。关闭页面只停止观察，不取消任务；观察窗口结束后可点击“继续观察”。
6. SUCCEEDED 或 PARTIAL 且有产物时，点击“核验并预览报告”或“下载 Markdown”。PARTIAL 需阅读限制和未覆盖范围。

“本页已知任务”不能恢复完整服务端任务列表。重新登录后可打开已保存地址，或输入已知任务 ID。来源撤销后下载可能被拒绝，页面会清理不能继续显示的报告。

## 偏好、运行和用户管理

在“个人偏好”新增希望长期保存的偏好，之后可查询、更正或删除。版本提示冲突时核对最新记录，页面保留草稿，不自动覆盖。

在“运行检查”查看本人实际执行记录，进入详情查看节点、连线、时间和已知用量。未完成或缺失记录显示不完整，费用 UNKNOWN 表示没有完整价格依据。

管理员在“用户管理”创建普通用户时，将一次性临时密码交给对应用户；关闭展示后前端不再保留该密码。新用户首次登录需要改密。管理员跨库读取权限不授予他人资料的写权限。

## 常见提示

2026-10-05 新增的媒体与费用操作：

- 在报告任务页选择“演示文稿”或“教学视频”，填写选项与费用上限，选择 1～6 份来源。PPT 总页数为 2～12 页，包含来源页；视频人物、声音、场景只选服务端登记项。
- 创建只登记规划任务。待预览就绪后核对内容、来源、覆盖、目录版本和估算，再批准当前版本与费用。编辑会产生新版，旧批准与旧 PPT 附件失效，原费用和期限不会重置。
- 视频在“整片 API 与声音规格”中选择统一 API；有声为 NATIVE，无声为 NONE。有台词不能使用无声。结果未知时保留原 ID 与费用预留，不重复购买。
- PPT 技术检查通过后，可核验逐页 PNG 或下载候选 PPTX；视频候选可认证播放与下载。下载会重新核对权限，不能访问时清除预览。结构检查不等于人工图文验收。
- 在“本人质量验收”填写真实检查说明，明确接受或拒绝。拒绝不授权新购买。未验收时不显示完成 100%。
- “费用记录”按任务、运行、入库代次查询已知 ID。入库需要 ingestionId，不能用文档 ID。估算、预留、未知和模拟分别展示；估算不是供应商实付账单。
- 管理员在“运营与审计”选择 1／7／30 天窗口查看计数和币种聚合，审计用上一页／读取后续按 ID 游标查看，不展示私人正文。

## 常见提示（原有流程）

| 提示或现象 | 处理方式 |
| --- | --- |
| 文档长时间 RECEIVED / 处理中，任务长时间 QUEUED | 保留资源 ID、状态及时间，联系后端核对索引和 Worker；不要重复上传或反复创建报告 |
| 页面显示 401 或登录到期 | 按提示重新登录；原密码错误的提示在改密页单独处理 |
| 403 / 来源不可读 / 历史 RESTRICTED | 核对当前权限和来源状态；受限正文与引用不会继续展示 |
| 会话、文档或章节版本冲突 | 读取最新版本和历史，重新核对；旧章节游标已清除时重新加载当前结构 |
| SSE 未完整交付 | 核对服务端历史；不能把未结束草稿当最终回答，也不要直接重复发送 |
| 429 登录限流 | 等待服务端限流窗口恢复，再显式登录 |
| 报告 PARTIAL、覆盖未完成或费用 UNKNOWN | 依据实际限制使用结果；不把部分结果当全文验收或把未知费用当零 |

仍有疑问时保存资源 ID、页面提示和发生时间；当前能力边界见 [联调边界](../接口联调/integration-gaps.md)。
