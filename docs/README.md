## 后端资料来源

[前端接口与联调说明](接口联调/前端接口与联调说明.md) 是本前端对接的唯一协议基线，来源于邻近后端项目的 [同名文档](../../Novid/docs/前端接口与联调说明.md)。迁移仅调整本地引用路径，接口正文、示例和 S01～S06 约定保持不变。后端更新时先同步这份基线，再核对前端实现和边界。

协议中引用的 [后端测试验证与验收报告](../../Novid/docs/测试验证与验收报告.md)、[后端部署配置与运行维护](../../Novid/docs/部署配置与运行维护.md) 和 [后端项目开发进展](../../Novid/docs/项目开发进展.md) 仍由后端项目维护，不在前端复制第二份。它们需要同级 `Novid` 检出目录；单独分发前端时，需要由后端同时提供对应材料。后端的测试结论不替代本前端的浏览器或真实模型验收。

仓库根目录还保留两份原始资料：[前端架构规划](../AI模型应用开发学习验证项目前端架构.md)、[旧联调说明](../frontend-development-guide.md)。它们属于 2026-10-03 历史设计与协议，不作为当前功能清单；其正文保留历史描述，当前说明从本索引进入。

## 维护与更新

| 发生的变化 | 需要更新的文档 |
| --- | --- |
| 页面、按钮或用户操作流程变化 | 使用说明中的功能介绍、操作说明 |
| 开发环境、代理、目录或部署配置变化 | 开发与部署；必要时更新项目根 README 的启动入口 |
| 后端协议发布或契约不一致 | 同步接口基线，更新 integration-gaps，核对实际实现；本地疑问先写边界，不擅改后端原文 |
| 新增或调整功能 | 更新日常说明，在开发维护中新增 `development-YYYY-MM-DD.md` |
| 执行新一轮验收 | 在测试验收中新增 `live-integration-YYYY-MM-DD.md`，更新测试指南的报告索引；同日多批次增加后缀并分别记录 |
| 文档移动、增加或归档 | 更新本索引、项目根 README、文档内引用，检查本地链接 |

日常指南使用稳定文件名，并注明更新日期和依据。历史报告按日期保留，复测作为新增批次追加，不抹掉初次失败、跳过或未覆盖场景。报告记录环境、命令、结果、证据、清理和限制；不保存真实密码、令牌或模型密钥。脚本和包版本以工程文件为准，指南不另行维护一套参数表。

移动或更新文档后，在项目根目录运行 `pnpm docs:check`。它检查根 README 和 docs 下 Markdown 的本地链接目标是否存在，跳过代码块和网络链接；不检查网页可达性或章节锚点。后端资料链接需要邻近 `Novid` 项目目录。根目录两份历史原始资料的正文不纳入当前指南链接检查。

本次旧路径迁移：原 `docs/前端接口与联调说明.md` 和 `integration-gaps.md` 进入接口联调；`backend-contract.md` 进入接口联调/历史并加日期；`development-2026-10-04.md` 进入开发维护；`version-validation.md` 和两份 `live-integration-*` 进入测试验收。后续引用使用新路径。
