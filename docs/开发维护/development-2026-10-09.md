# 2026-10-09 前端联调契约更新

依据 [最新接口文档](../接口联调/前端接口与联调说明.md) 更新现有 Vue 项目。

## 实现内容

- 导航改为“学习与制作”，创建入口仅提供 QUIZ_GENERATION、KNOWLEDGE_COMPILATION、NOTES_PPT、NOTES_VIDEO。
- 自测支持完整题量、题型、难度选项；整编支持详略和章节上限。学习使用 FIXED，媒体使用 PLANNED；明确发送对应类型选项，媒体金额按 JSON number 发送。
- 学习参数变更时更新幂等键，结果不确定时同参数手动复用原键，不自动重复创建或付费操作。
- 任务进度按服务端实际 steps、totalSteps、percent 展示，支持六阶段；媒体未人工接受时不显示 100%。Worker 关闭、学习容量上限和工作流错误按实际状态提示。
- 新增私人 GET /tasks/{id}/result 契约校验和展示。自测答案与解析默认折叠；整编按目录分组关联章节正文。通过 itemIds 匹配引用，定位前复核文档版本、处理代次与原文；引文使用整份原文的绝对 UTF-16 区间。
- 学习模型质检通过仍显示人工质量待验，不调用媒体人工验收接口。来源失效或重新核验失败时清理私人结果；页面离开中止相关读取。
- 旧 FAQ／RESEARCH_REPORT 仅显示历史记录、合法 Markdown 与保存计划，不提供创建和恢复入口；服务端 410／WORKFLOW_RETIRED 保留实际错误。
- 媒体仍分生成前批准与生成后人工验收；新 PPT 的媒体计划空数组显示正常缺省说明。
- 普通 HTTP、代理和 SSE 业务错误保留 HTTP 状态、code、message、retryable 与初始响应 X-Request-Id；retryable 不触发自动重复请求。
- 同步 README、当前使用说明、功能介绍与联调边界；真实后端测试脚本已改为两类学习任务及六阶段结果。

## 验证边界

初次契约更新使用 Node.js 24，受控协议与浏览器测试只验证请求、响应和页面行为，未执行真实模型测试。用户随后启动后端，已完成 [同日真实联调](../测试验收/live-integration-2026-10-09.md)：资料整编生成通过，自测结构校验与运行图写入失败。未购买媒体，学习内容仍待人工质量判断；2026-10-04 旧报告记录保留为历史。

最新接口文档由用户更新，其后端源码、环境说明和报告的相对链接不适配本前端目录；本次保留原文。文档全量链接检查中的既有失效链接将单独记录，不创建占位文件或改写协议内容。
