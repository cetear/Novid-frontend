# 2026-10-13 模型调用校验与全文查询

依据接口基线新增的模型调用协议，更新运行检查页，保留上一轮整编续跑改动及用户协议更新。

- 默认运行图请求 `graph?view=summary`，点击节点再按 spanId 查询详情；旧的节点元数据、时间线、用量与历史未采集提示保留。
- 业务 AGENT 按节点名称查询各次尝试；MODEL 节点通过 observation.callId 打开调用详情。运行页也提供无 nodeId 的独立调用列表，在图尚未持久化时仍可排查归档。
- `/calls` 实际返回 Detail 数组，每项为 `{call,input,output}`，而非裸 CallRecord。前端已按后端 DTO 和真实响应校验。
- 分开呈现提供方 callStatus 与本地 validationStatus、HTTP／校验／归档耗时、契约和诊断。JSON Pointer、UTF-16 坐标、行列、首尾摘录、位置来源与截断标志均按原值展示，内容采用纯文本。
- 全文每次请求 8192 UTF-16 单位，使用服务端游标翻页，替换当前页而不累积正文；输出支持完整提供方响应和模型文本两种视图。下载通过同源 Bearer 请求，完整接收后才保存 UTF-8 文本，失败不保存局部文件。
- READY 与 WRITING、NOT_CAPTURED、EXPIRED、ACCESS_REVOKED 等状态区分展示；没有正文不伪装为空。409 全文不可用和 500 损坏均清理正文、预览和诊断，不触发模型重跑。
- 请求随节点、调用、运行切换和组件退出失效；重新核验调用会中止分页及下载。401／403／404 清理私有内容；服务端返回 ACCESS_REVOKED 描述时关闭全文读取与下载。

新增 Zod 契约及归档组件，给 useLoad 增加 reset 用于中止并清理当前请求。Vitest 环境不自动导入 Element Plus CSS，浏览器和生产构建保持样式加载。真实 UUID 长标识按钮可换行，375px 页面无横向溢出。

单元测试覆盖 Detail 列表、摘要接口、过滤参数、opaque 游标及有界正文；浏览器测试覆盖纯文本安全展示、分页替换、模型视图、下载、迟到正文、403 权限清理，以及 409／500 后清理旧私有快照。
