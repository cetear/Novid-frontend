# 2026-10-16 学习续跑与延续图适配

依据最新接口基线更新前端，保留用户已有的接口文档和登录页改动。

## 本轮改动

- 将整编续跑组件复用于自测与整编，并命名为 LearningRetry。入口依据所查看任务的 taskType 与 FAILED 状态判断，自动读取 retry-plan；资格不符时只显示计数、余量和阻断原因，隐藏提交表单。
- 统一提交按钮为“从断点继续处理”。请求仍为 CONTINUE、对应状态版本与明确追加额度，不增加 taskType。网络结果不确定时继续锁定并复用原键和参数；409 后刷新原任务与计划，400 额度不足后重新读取余量并保留追加值。202 后刷新并观察原任务，不新建任务。
- 阅读诊断接受 structure-read-v1、structure-read-v2-compact 和 structure-read-v3-progress，展示冻结协议；completedFragments 和 fullSourceRead 均使用服务端证明，不由阅读包完成或观察数推算。
- 图契约保留可选 nodeRuns 映射，历史节点详情与调用使用原始运行 ID。运行检查默认使用 continuation 摘要，可切换 execution，仅看本次执行。说明合并节点数与本次 nodeCount 的区别，历史失败祖先不代表当前运行失败，用量也注明是否包含历史。
- 模型文本索引返回 409 时清理旧私有快照并提供“改看原始响应”，点击后重新核验调用，仅在原始响应仍为 READY 时读取。V30 前旧归档缺失索引不会触发新模型调用；过期归档不展示旧预览。

## 验证

新增协议兼容和覆盖证明单元测试；浏览器覆盖自测续跑、额度不足、同键重试、非失败状态不展示表单、历史节点原始运行查询、execution 切换、旧索引回退及过期清理。暂停任务仍使用原有恢复动作，媒体不提供失败学习续跑入口。

本轮只执行契约／模拟回归，不重新创建真实模型任务；本次代码适配不能代替真实后端的成功续跑、归档索引性能或运行中拓扑验收。
