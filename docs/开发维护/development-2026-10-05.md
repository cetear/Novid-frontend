# 2026-10-05 接口同步与 Novid Studio 重设计

依据 [前端接口与联调说明](../接口联调/前端接口与联调说明.md) 最新 S07–S10 及相邻后端 DTO／Controller／业务校验同步。保留用户原先对协议文档的修改，不改后端配置、凭证或数据库。

## 实现

- 深靛侧栏、蓝紫主色、浅色内容区；统一标题、统计卡、表单、资料卡、报告、偏好、账户和登录界面。设计规则保存在 [MASTER](../../design-system/novid/MASTER.md)。
- 桌面固定导航；窄屏使用有焦点管理、Escape 和关闭按钮的抽屉。路由切换聚焦主要内容，提供跳过导航链接、可见焦点与减少动效支持。本人会话管理默认收起。
- S07 本人运行／任务／入库代次费用查询，以及管理币种聚合；精确小计仅展示，不浮点累加。旧无账记录允许币种／上限为空，未知不当免费。
- S08 管理指标与审计，窗口 1～30 天与 afterId 游标；历史缺字段保留未知，不把 DELIVERABLE 当浏览器交付。
- S09 PPT／视频 PLANNED 创建；媒体目录、能力、版本化预览编辑、单片 API 选择、独立费用批准、计划／操作／实测时间轴。缺价格不可选择，有台词不能无声，未知原操作阻止编辑重购。
- S10 当前版本检查、候选 PPTX、认证 PNG 预览、MP4 播放／下载、SRT 下载与本人验收。Blob 只来自认证读取；有检查快照的附件验证 SHA256。编辑估算 null 展示“待重新核价”；修改、拒绝、撤权、身份切换及页面退出清理私人附件。
- 未提供后端不存在的任务列表、退款、自定义提供方端点、价格写入或重新购买 API。

## 验证范围

本轮自动化使用受控接口，不调用真实付费模型或购买媒体；浏览器截图中的内容为测试夹具，不代表真实 PPT／视频质量通过。最新真实媒体能力和未验项仍以后端验收报告为准。

测试覆盖裸 JSON、204、类型化媒体选项、原幂等键、未知费用、单片 API 约束、PNG Bearer 读取、版本编辑撤下附件、403 清理、管理游标、移动 Escape、375px／横屏／平板／桌面与减少动效。

终端默认 Node 20 与 jsdom 依赖不兼容；改用本机已有 Node 24.19.0 完成验证，没有安装或更改系统运行时。

验证结果：生产构建（含 TypeScript）通过；ESLint、Prettier 通过；7 个单元／接口测试文件共 66 项通过；18 项受控浏览器流程通过；14 份 Markdown 中 91 个本地链接检查通过。
