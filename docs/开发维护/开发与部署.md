# 开发与部署

更新日期：2026-10-04。依据 [package.json](../../package.json)、[Vite 配置](../../vite.config.ts)、[环境示例](../../.env.example) 和 [部署参考](../../deploy/nginx.conf.example)。

## 环境与启动

要求 Node.js 24，至少 24.12.0 且小于 25；pnpm 11.19.0。版本约束由 package.json、.node-version、.npmrc 和 pnpm-lock.yaml 维护。

在项目根目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

开发地址默认 `http://127.0.0.1:5173`，后端默认 `http://localhost:8080`。没有默认业务账号，需要后端管理员提供。首次依赖预构建可能耗时，等待开发服务器就绪后访问。

## 同源代理与配置

浏览器仅请求同源 `/api/v1`，开发服务器代理到后端。需要更换后端时，将 `.env.example` 复制为 `.env.local`，修改 `API_PROXY_TARGET` 并重启开发服务器。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `VITE_API_BASE` | `/api/v1` | 浏览器 API 路径，必须保持同源路径 |
| `API_PROXY_TARGET` | `http://localhost:8080` | 开发服务器代理目标，不进入浏览器 |

模型地址、模型密钥、数据库和后端 Worker 参数由后端维护，不放入前端环境变量。登录令牌只在内存保存，刷新会清除登录和本次登录的已知资源索引。

## 工程目录

| 目录 | 职责 |
| --- | --- |
| `src/app` | 启动、路由、导航、布局、身份策略注入 |
| `src/features` | auth、knowledge、chat、approvals、tasks、memories、runs、settings、admin 等业务功能 |
| `src/shared` | DTO 校验、通信、SSE 解析、安全 Markdown、基础组件；不依赖 app / features |
| `tests/integration` | 通信、协议、版本、状态与安全显示测试 |
| `tests/e2e` | 受控接口浏览器回归与真实后端联调 |
| `scripts` | 后端预检等工程工具 |
| `deploy` | 同源静态服务与代理参考配置 |
| `docs` | 使用说明、开发维护、接口联调、测试验收 |
| `var`、`playwright-report`、`test-results` | 被忽略的测试证据、截图与报告 |
| `dist` | 生产构建输出 |

接口字段和权限以 [后端协议](../接口联调/前端接口与联调说明.md) 为准。按业务模块继续开发，并同步 [功能介绍](../使用说明/前端功能介绍.md)、[操作说明](../使用说明/前端使用说明.md) 和 [联调边界](../接口联调/integration-gaps.md)。实现记录按日期保存，参考 [2026-10-04 开发记录](development-2026-10-04.md)。根目录架构规划是历史设计，不作为当前功能清单。

## 构建与验证

```powershell
pnpm type-check
pnpm lint
pnpm format:check
pnpm test
pnpm build
```

`pnpm preview --host 127.0.0.1 --port 4173` 用于检查构建产物。浏览器契约回归和实际模型联调分开执行，命令、账号和结果记录要求见 [测试与验收指南](../测试验收/测试与验收指南.md)。

## 部署参考

生产产物在 `dist/`。由现有静态服务或反向代理同源部署前端和后端 API；参考 [nginx.conf.example](../../deploy/nginx.conf.example)，按实际环境替换静态目录、域名、端口和上游。当前仅提供参考，未完成生产发布或实际 nginx 验收。

配置 SPA 页面路由回退，同时保持 API 和缺失静态资源返回真实状态。SSE 代理关闭缓冲与缓存，保留 Authorization，并使用合适的读取超时。入口和业务响应不缓存，带哈希静态资源可长期缓存。协议中的后端环境要求见 [后端运行维护文档](../../../Novid/docs/部署配置与运行维护.md)。
