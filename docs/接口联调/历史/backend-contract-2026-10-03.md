| 约定 | 前端实现 |
| --- | --- |
| 裸对象、裸数组 | Transport 不读取 data 包装 |
| 200 空正文 | 显式 empty 模式 |
| 文件与报告 | 带 Bearer 的文本 fetch，校验 MIME、声明 / 实际大小与 UTF-8；默认单次 10 MiB |
| 不透明令牌 | 内存保存，身份 epoch 变化中止旧请求并拒绝晚到响应 |
| 严格字段 | 功能 API 显式构造字段，PATCH 不展开响应对象 |
| 0 基分页 | 上一页 / 下一页，最大 page=10000，不伪造 total |
| Scope | 列表 query；问答 / 任务 JSON；owner 筛选时不显示混淆统计 |
| 上传 / 创建任务 | 一次操作生成幂等键，相同参数未知结果可手动复用，不通用自动重试写请求 |
| SSE | POST / Bearer / 流式 UTF-8 + eventsource-parser；done 覆盖累积结果，正常 EOF 才完整 |
| 私人资源 | 任务、确认、偏好、运行、报告不提交知识 Scope |
| 版本 | 库 version、文档 documentVersion、memory version 分开；冲突读取后由用户核对 |
| 轮询 | 查询完成后调度、隐藏页面暂停、最长 30 分钟，终态停止；不推进后端状态 |

## 真实联调前提

真实模型闭环需要 SEARCH_ENABLED、知识索引、INGESTION_WORKER_ENABLED 和 TASK_WORKER_ENABLED 正常；没有前端启用 Worker / 初始化索引的接口。2026-10-03 已使用受控账号连接 8080，资料、账户、权限、笔记确认与任务动作通过；健康 503 / DOWN，问答 SEARCH_UNAVAILABLE，完整 AI 链路仍待环境恢复。详细结果见 [真实联调记录](../../测试验收/live-integration-2026-10-03.md)，未将 Mock 标为真实验收。

## 人工验收清单

- [ ] 代理登录与健康请求正常，Bearer 只在头中；USER / ADMIN 权限均由服务端确认。
- [ ] 临时密码强制改密，错误原密码 401 后 me 有效仍保持登录；改密后旧 token 失效。
