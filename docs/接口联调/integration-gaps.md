# 联调边界与后续能力

更新日期：2026-10-09。正式应用只调用 [当前协议](前端接口与联调说明.md) 的已实现接口，不回退到 Mock。学习更新与验证边界见 [本次记录](../开发维护/development-2026-10-09.md)。

| 当前限制 | 界面处理 |
| --- | --- |
| 任务 / 审批 / 产物无列表 | 本次登录的有限已知 ID、深链接重新核验；会话列表不能替代任务中心 |
| 禁用库无完整管理列表 | 禁用前保留 ID，已知 ID 重新启用 |
| 历史原文无版本查询 | 旧证据只展示证据文本；历史来源入口明确打开当前文档，不误定位旧版本 |
| 模型上下文有界 | 会话历史保存与有限模型窗口独立；长期偏好须明确保存 |
| 资料工作流资源有界 | 1～6 份文档，默认原文合计 1,000,000 UTF-8 字节、256 个产出目标；按创建时的服务端策略保护资源，不将资源上限视为固定产出数量 |
| 学习结果没有人工验收写接口 | 展示模型质检及人工待验标识；完整读取不等于穷尽知识点，自测折叠答案不提供考试保密 |
| 旧 FAQ / RESEARCH_REPORT 已停用 | 移除创建、恢复与旧计划入口；仍存在的本人历史记录和合法产物只读，V23 清理旧执行版本数据 |
| 路由快照未新增持久历史明细 | 只展示本次 AiResult.route；历史不能补造 Token / 路由详情 |
| 运行图可能缺失或尚未写入 | 手动刷新、显示 incomplete / 缺失节点 / 未结束节点；不生成静态步骤冒充真实运行 |
| 费用估算不是实付账单 | 本人运行／任务／入库代次费用独立查询；按币种分开显示小计，预留和未知不合并冒充实付，无退款写入口 |
| PPT / 视频已有契约，真实质量仍有未验项 | 开放规划与审批入口；仅使用后端登记项，能力缺失如实报错，结构检查与本人验收分开 |
| 视频同片单 API / 版本 | 整片统一配置，有台词不能选无声；未知提交不允许编辑重购或自动替换 API |
| PPT 当前版本与私有附件 | 自动或指定总页数包含动态来源页；预览展示内容计划引用，编辑锁定数量、ID、顺序与配图模式；Bearer 获取 PNG / PPTX Blob，修改后撤下旧附件 |
| 管理指标与审计有限 | 仅管理员读取无正文计数和访问元数据，游标分页；不视为完整安全日志或全实例监控 |
| 无全文搜索列表 / 模型配置管理 | 不注册不存在的接口或配置入口 |

当前资料驱动 V2 结果见[V2 真实联调](../测试验收/live-integration-2026-10-09-v2.md)。[同日早期批次](../测试验收/live-integration-2026-10-09.md) 已通过入库、JSON / SSE / 多轮 / 工具、笔记、资料整编、费用与账户权限，自测 #185 的结构校验及运行图失败保留为历史。视频目录与能力当时为空，媒体生成和人工质量仍未验。前端兼容工具引用的 sectionId=null，并将历史审计空字段显示为“历史未知”。

[2026-10-04 真实模型联调](../测试验收/live-integration-2026-10-04.md) 的两种旧报告和运行图成功保留为历史，不能作为当前环境通过的证据。2026-10-03 的 [记录](../测试验收/live-integration-2026-10-03.md) 也保留；本次未改变后端开关、凭证或索引配置。

ADMIN 的资料跨库读取不扩大会话、任务、计划、入库管理和运行图的本人权限，也不授予他人资料写权限。403 时清理相应内容，不猜测资源是否存在或自动扩大范围。

不会自动重放模型调用、确认、task actions 或新代次操作。会话结果不确定先读取版本和消息；上传 / 任务 / 会话创建只在同参数下手动复用原幂等键。recover 只提前调度原失败代次，不能重置预算或自动改为 retry / reprocess。
